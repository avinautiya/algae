Supplement Material for "Drainage of an ice-dammed lake through a supraglacial stream: 
hydraulics and thermodynamics" Ogier et al, submitted.

This zip folder has to be un-zip. it contains 3 sub folders:

1. data

where all raw data are stored

2. PlaineMorteLake_hydro_thermodynamics.jl

that contains the code (Ijulia notebooks) to process de data in the eponym folder. 
Notebboks are provided with documentation in the README and in the notebooks themselves. 
Don't mover the folder location: the path to the data folder is already set in the code.

3. Products

The products (=data processed) are the results and the plots presented in the article. They can be taken as such without modifications (e.g. for numeral modelling simualtions) 
or they can be re-processed by running the notebooks.
