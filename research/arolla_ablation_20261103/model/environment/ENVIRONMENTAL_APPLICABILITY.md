# Environmental input audit and a bounded next model

This addendum changes no frozen model or score. It contains no new target prediction. The failed Arolla PDD-superiority result remains. This is sub-debris ice ablation, not validation of the stream–cliff coupling. Weather-conditioned reconstruction is distinct from a lead-time forecast.

## What was actually available and used

`INPUT_AVAILABILITY.json` is regenerated by `input_audit.py` from the canonical parsed source (SHA256 recorded). Over the maximal primary visit-day envelope (28 July through 11 September inclusive), all 1104 hourly labels have air temperature, RH, wind speed/direction, four radiative components and nominal sensor heights. Precipitation is present for 1072 hours and missing for 32. Pressure and snow depth are missing for all 1104. PDD used only air temperature; radiation-dose used only shortwave in/out; constant rate used elapsed time. Thus unused available drivers are real opportunities for physically justified comparison, not demonstrated causes of bias.

The source archives and metadata are [DCGMIP inputs](https://doi.org/10.5281/zenodo.3047649). Source metadata limitations:

Arolla snow metadata includes 30 August during evaluation; absence of native snow does not prove snow-free conditions. Source uncertainty 0.1 m for stakes has unspecified probability and reading-versus-interval semantics; retain both bounded interpretations. Multiple stakes share weather and dates, not independent glacier events.

## One physically grounded next model

A **radiometer-constrained transient debris column**, evaluated as an established physical model, is the next justified candidate. On independently confirmed bare-debris periods, derive

Ts+273.15 = [(LWout − (1−epsilon)LWin)/(epsilon sigma)]^(1/4).

Solve C T_t = k T_zz in a fixed debris layer with this observed top boundary. The lower boundary requires an explicit temperate-ice gate or a cold-ice enthalpy model; compute its signed flux rather than clipping it positive. Give initial thermal state and spin-up sensitivity explicitly. Snow-covered/unknown periods must have independently observed snow state or bounded snow-layer scenarios, and cannot enter the bare-boundary contract unnoticed.

This uses measured surface radiation to avoid separately inferring unknown atmospheric closure coefficients. It therefore predicts melt conditional on that observation, not autonomous future weather or satellite-only melt. One Arolla calibration interval can identify at most one effective parameter combination; fitting k, heat capacity, moisture and roughness separately would be unsupported. Do not add a neural network to evade that rank limitation.

## Exact elementary conservation diagnostic

Take z=0 at ice and z=d at the debris surface. For constant k,C, fixed d, basal T=0 and no internal/advection heat, define I=integral[(1−z/d)T dz]. Integration by parts gives

q_ice = (k/d) Ts − C dI/dt,
Q_ice = (k/d) integral(Ts dt) − C [I(end)−I(start)].

If Tmin ≤ T(z,t) ≤ Tmax everywhere throughout, then the integrated storage correction is bounded by C d (Tmax−Tmin)/2. This is signed net interface heat. Converting it to gross observed ice ablation requires resolving cold-ice uptake, refreezing and every other interface term; energy conservation alone does not establish that equivalence. `energy_contract.py` enforces the basic phase/scope refusals.

For illustration only, C=1.8 MJ/m³/K, d=0.06 m and a 30 K temperature range give a 1.62 MJ/m² correction bound (~4.85 mm water-equivalent latent energy). C and the range are illustrative, not measured Arolla inputs. This bound can rule out the claim that arbitrarily large multi-week bias is explained by storage alone under those assumptions. Source ±10% k and d give k/d=13.09–19.56 W/m²/K by box propagation, not a confidence interval. The identity is elementary; no new theorem is claimed.

## Existing methods and the actual novelty gate

[Laha et al.](https://doi.org/10.1017/jog.2022.35) already estimate sub-debris ablation from temperature profiles using homogeneous/two-layer conduction and Bayesian inference, and compare against stakes. Therefore neither observed-boundary conduction, two layers nor Bayesian conductivity inversion is novel here.

The [Pirámide properties release](https://doi.org/10.5281/zenodo.11581073) already provides methods for conductivity and roughness estimation/calibration, moisture-aware inputs, thermistors, meteorology and camera-derived ablation. Generic joint k/z0 optimization is not a novelty claim either. Its 62.7 MB archive is a promising next process-data audit, not a scored dataset in this addendum.

Full debris surface-energy-balance approaches already include radiative, turbulent and conduction processes. Adding these terms improves physical scope relative to our three simple baselines but does not establish novelty relative to professional models. The testable contribution would need an independently supported new regime, identifiable mechanism or demonstrably useful robust prediction bound, not renaming these equations.

## Different evaluation support and stop rules

1. Do not tune to inspected Arolla evaluation intervals. Arolla can remain development evidence after its frozen failed comparison.
2. Miage 2005 stake 114 has native forcing covering all visit-day hours for 16 June→28 July→7 September and source ice-ablation targets. It is a different site/event but its raw observations have already been inspected, so call any new evaluation retrospective transfer, never blind. Exclude source Miage conductivity: it was derived from the same ablation targets. Check native radiation, snow-free provenance, thickness change and initial-state support before freezing a model. First-interval local persistence is a strong comparator with additional local target information, and that asymmetry must be explicit.
3. Prefer auditing the distinct Pirámide properties release for multi-depth temperature/moisture and camera ablation. Check whether observations overlap existing inspected Pirámide targets; exclude overlapping dates from any claim of untouched evaluation. Camera automation, calibration and property-fitting dependencies must be traced first.
4. Before any scores, freeze parameters, phase rules, target units, visit/label timing boxes, all comparator fits and uncertainty treatments. Require identical ice target and footprint; contextual ambiguous-component DEBCF output cannot alone establish superiority.
5. Stop if snow/phase support is insufficient, if inferred properties use evaluation ablation, if the model needs more identifiable parameters than independent calibration information, or if predicted differences are smaller than measurement/timing/numerical bounds. A failed test remains a result.

No amount of adding known environmental terms guarantees field superiority, originality or a publication outcome. This audit supplies executable input diagnostics and conservation gates so the next result can be credible either way.
