# Freeze-ready conditional plate-signal experiment

Implemented `plate_experiment.py` uses observed top/bottom thermometers and a constant-effective sensible-conduction hypothesis to predict the archived raw signed plate signal. Seven tests pass, including exact signed flux-scale identification, an analytic steady gradient and a held-out-target perturbation test that leaves every fit/prediction unchanged. Exact original Dirichlet source is included. No January test score has been computed at delivery.

`FREEZE.json` fixes source/data hashes and non-performance support counts. Parent must publish that freeze and supply its40-character commit BEFORE execution. Full source audit and interpretation are in `PROTOCOL.md`.

Native averaged-flux/melt validation is BLOCKED: interval alignment, physical plate orientation and in-season sensor migration remain unresolved. Executing the separate representative-point diagnostic requires explicit `--interpretation representative_point_diagnostic`. It predicts archived means treated as point representatives, not exact integrated heat flux. Measured subcolumn endpoints allow cold observations mathematically, but no phase-change or ice-melt claim follows.

Example from this directory:

```
python3 -m unittest -v test_plate_experiment
python3 plate_experiment.py PATH/CHANGRI_ALIGNED_AUDIT.json --out NEW_DIR --commit PUBLISHED_FREEZE_SHA --interpretation representative_point_diagnostic
```

The data file is generated by the independently verified Changri loader or exists in `research/prediction_extensions_20261103/benchmark/CHANGRI_ALIGNED_AUDIT.json` on the published extension branch. Its SHA must match the freeze. A full-season conductivity fitted to melt is never used. Site1alpha is trained on interior temperatures; both raw flux amplitudes/orientations are trained only on early plate readings. Site2inherits site1alpha because no interior thermometer exists. All61alpha objectives and all comparator outcomes are retained. Do not choose test conditions, clock conventions, sign or hyperparameters after seeing scores.

This is a potentially useful observation/parameter-identifiability test, not established novel physics or a new validated glacier-melt model. Moisture, phase change, advection and sensor-position error can invalidate its simple effective conduction model. A ridge win or numerical refusal must be preserved.
