# Independent review of weak thermal graphs and calibrated prediction enclosures

## Verdict

The continuous calibrated-heat enclosure is mathematically coherent for its **declared fixed-coefficient linear polytope**. An independent 100-case two-dimensional vertex enumeration matches the implementation's extrema to 4.55e-13 mm water equivalent. This is an implementation result, not a new theorem, field-coverage guarantee or evidence of improved melt prediction. No native Lirung ablation file was opened. A literature search automatically exposed published seasonal rate summaries in Chand2015's abstract; any subsequent Lirung comparison must acknowledge that team-level literature exposure.

## What was actually checked

`independent_ratio_audit.py` intersects every pair of polygon boundary lines, retains all feasible vertices and evaluates each ratio there. It does not use the Charnes–Cooper transformation for its reference. All100 bounded, positive-denominator cases agree. Two counterexamples explicitly distinguish goal knowledge from parameter knowledge: proportional future/TRAIN coefficient vectors give an exact ratio despite broad parameter bounds; a perfectly known TRAIN edge gives almost no information about an independent future edge. The source code SHA and every numerical difference are retained in `INDEPENDENT_RATIO_AUDIT.json`.

The inspected `ratio_enclosure.py` correctly transforms y=g/(c·g),t=1/(c·g), imposes `c·y=1`, transforms all original bounds, and checks recovered witnesses. Bounded original variables exclude t=0 in exact arithmetic. Positive TRAIN heat is checked before division. For the ratio interval [L,U], its midpoint has minimax absolute error (U−L)/2; no parameter estimate needs to be unique.

Numerical qualifications remain: HiGHS floating-point feasibility is not outward-rounded interval arithmetic; the absolute1e-12 denominator,1e-9 heat and1e-6 feasibility cutoffs are unit-dependent. Near-singular/poorly scaled inputs should abstain or be nondimensionalized, not be advertised as exact numerical certificates. The explicit rejection thresholds are safety conventions, not physical constants.

## Four gaps before calling this a source-error-constrained physical prediction certificate

1. **Errors in both variables.** Native temperatures enter the weak-equation design matrix, storage change and future heat integrals. A polytope constructed using only the observed design matrix with a residual tolerance does not automatically contain every model generated by admissible latent true temperatures. Products of uncertain conductance and uncertain temperature differences are bilinear. A valid outer relaxation can bound these products, retain shared sensor offsets across time and include geometry uncertainty; an inner fit cannot be called an enclosure of the full error model. A bounded sensor-error formula must be derived and tested independently, not inferred from fit residuals.
2. **Phase.** The linear goal `f·g` is signed heat. It equals latent release only on an independently established warm melting branch with the specified boundary and negligible missing sensible/phase sinks. Cold-debt repayment is positively homogeneous but generally piecewise linear in the full heat history, rather than a single fixed coefficient vector. A union of explicitly justified linear branches or a conservative nonlinear outer bound is needed before applying the ratio solver to that history.
3. **Adaptive drift.** Updating graph conductances from past temperatures is causal state-conditioned inference, not an autonomous forecast of future weather. A certificate over independent day-specific parameters needs explicit drift/physical coupling bounds; arbitrary daily adaptation can remove the common-scale cancellation and make transfer intervals broad. The future measured temperatures must be labelled available contemporaneous inputs, not forecast outputs.
4. **Discrepancy and coverage.** Conductive-model residuals do not bound all unmeasured advection, pore-phase change, migrating geometry, basal storage or unknown measurement footprint. An empty set means assumptions fail; a narrow nonempty set means only conditional agreement. Unknown discrepancy cannot be silently assigned zero because the resulting interval is attractive. Calibration-target uncertainty must be included jointly; one exact positive scalar target is an assumption in the current API.

## Closest prior work and exact potential distinction

- [Laha et al.2022, DOI10.1017/jog.2022.35](https://doi.org/10.1017/jog.2022.35) already treats debris-temperature inversion and ablation, including vertically variable properties and Bayesian inference. The publisher page was rate-limited in this review; its methods are corroborated by the primary2025 papers below. Do not claim priority for heterogeneous temperature-based melt inference or minimal sensor use.
- [Melo-Velasco et al.2025](https://doi.org/10.1029/2025JF008360) explicitly compares alternative profile-based and melt-optimized conductivity methods. Its source calibration is not independent of its ablation target. A weak integrated graph is a discretization/estimation alternative, not new heat physics.
- [Beck and Nicholson2025](https://tc.copernicus.org/articles/19/2715/2025/) already investigates sensor precision, thermistor position and sampling errors, including Lirung forcing records, and supplies TC-DTD code. Therefore a claim that previous glacier inversions ignore numerical/sensor design is false. A prediction-functional enclosure would need direct comparison with their error analysis and Laha's Bayesian predictive approach.
- [Charnes and Cooper1962](https://doi.org/10.1002/nav.3800090303) establishes the linear-fractional transformation. [Lieberman and Willcox2012/2013, Goal-Oriented Inference](https://doi.org/10.1137/130913110) already targets prediction instead of full parameter recovery. [Afkham et al.2024](https://backend.orbit.dtu.dk/ws/portalfiles/portal/364393872/Afkham_2024_Inverse_Problems_40_075010.pdf) also treats uncertainty of inverse-problem quantities of interest. Neither goal-oriented inference nor a ratio LP is new general mathematics here.
- [Chand and Kayastha2018](https://www.climatenepal.org.np/sites/default/files/doc_resources/Chand%20%26%20Kayastha%20et%20al.%2C%202018%20SEAR.pdf) already links Lirung seasonal thermal properties and degree-day factors. [Chand et al.2015](https://piahs.copernicus.org/articles/368/21/2015/) already compares debris-thickness/season melt patterns. Temperature and stake footprints must be bound independently rather than matched by similar observed melt.

The **candidate specific contribution** is an operational algorithm that encloses a locally calibrated future melt functional over all positive thermal graphs compatible with *explicitly bounded, shared source errors*, then abstains when that functional is not constrained even though a least-squares parameter fit exists. Historical originality is not established by this bounded search. Demonstrating that its enclosures remain honest under adversarial sensor errors, and that useful predictions remain possible without identifying conductivity, would be a real testable numerical-method result. A broad claim of new glacier physics is unsupported.

## Falsifiable experiment, rather than a promised favorable outcome

Freeze a finite synthetic benchmark before running: analytically/independently generated layered conduction with irregular sensor positions, shared constant sensor offsets, time-varying bounded noise, known geometry and separate challenges for source terms, phase and migrating sensor positions. Compare Conway–Rasmussen, Laha's published method if reproducible, the weak-graph point fit and the continuous goal enclosure. Declare which methods have oracle noise bounds. Primary certificate criterion: no false coverage for all cases **inside the declared deterministic model class**; report interval width/abstention fraction and runtime, not only point MAE. Outside-class challenges test failure detection and must not be counted against a theorem that excludes them. Report coverage failures, even one, without retuning bounds after truth.

Then a fresh field comparison can test whether useful enclosure width and actual target coverage coexist under independently supplied geometry, sensor errors, local TRAIN ablation and future measured thermal profiles. That is an environmental test, not an implication of synthetic conservation. The current Lirung campaign aggregates and unresolved footprint/timing operator are insufficient to assume this test is ready.

## Conditional decision mathematics (established, useful)

For a genuine feasible target interval [L,U], let m=(L+U)/2,r=(U−L)/2. Any fixed baseline b has worst-case absolute error `r+abs(b−m)`, whereas m has r. This proves smaller **conditional worst-case** loss unless b=m, not that m beats b on the realized field outcome. Pointwise dominance over every y in[L,U] needs b sufficiently outside the interval: `b>=U+r` or `b<=L−r`; strict inequalities give strict dominance. If b lies inside a nondegenerate interval, y=b immediately disproves universal superiority. These formulas make a defensible abstention/decision rule, not guaranteed field success.

## Added coefficient-box enclosure audit

The subsequently added `coefficient_box_enclosure` is a valid conservative coefficient outer relaxation when g>=0, every coefficient truly lies inside its supplied coordinate box and TRAIN denominators remain positive. Pointwise `f_lo·g/(c_hi·g) <= f·g/(c·g) <= f_hi·g/(c_lo·g)` follows from coefficient order and nonnegative g; optimizing these limits over the same fixed P preserves containment. Discarding shared sensor correlations enlarges the set rather than asserting probabilistic independence. Independently enumerating all16 coefficient-box corners and all feasible polygon vertices for30 random cases agrees with the implemented enclosure to numerical precision (`COEFFICIENT_BOX_AUDIT.json`).

This addresses uncertain numerator/denominator coefficients only. P itself still must be an outer set for errors in weak-equation regressors/storage, and the goal must remain in an established linear phase branch. Negative lower future bounds appropriately trigger refusal in the current implementation rather than being silently clipped. Unknown calibration-target error is not covered by this fixed-positive-target wrapper.
