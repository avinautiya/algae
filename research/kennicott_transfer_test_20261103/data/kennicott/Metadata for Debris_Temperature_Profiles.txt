Metadata for Debris Temperature ProfilesData for Petersen, E., R. Hock, M. Loso, W. Guo, C. Markovsky, R. Yang, H. Han, D. Shangguan, and S. Kang, “Multi-year glaciological and meteorological observations on debris-covered Kennicott Glacier, Alaska, 2008-2023,” Geoscience Data Journal, Submitted January 2025.Data for debris temperature profiles is stored in subdirectory /Profile_Temperature_Records/. For each profile, there is a comma separated text file “[profile name].csv.” This file includes a column for Datetime recorded in UTC as well as a supplemental "Datetime_ADT" column 
recorded in Alaska Daylight Savings Time (GMT-08:00) in yyyy-mm-dd HH:MM:SS format, 
and a column for each temperature sensor. The header of each temperature sensor column is in the format “Depth: {x} cm,” denoting the depth from the debris surface. Temperature data is recorded in degrees Celsius and was measured on Onset Hobo Tidbit v2 integrated temperature sensor/dataloggers with a reported accuracy of ±0.2 C.In the subdirectory /Profile_Sensor_Depths/ we included comma separated files with the name “[profile name]_Depth.csv”, including a single column with the heading “Depth” and a record for the depth of each temperature sensor in cm. These files are intended to ease numerical analyses by end users.The comma-separated file “debris_thermistors_profiles_summary.csv” includes a summary of each debris thermistor profile, including the location of each profile reported in WGS84 decimal degrees.Works Cited:Petersen, E. I., R. Hock, G. J. Fochesatto, and L. S. Anderson, “The significance of convection in supraglacial debris revealed through novel analysis of thermistor profiles,” JGR: Earth Surface, 127, e2021JF006520. https://doi. org/10.1029/2021JF006520, 2022.
