# Portable chemistry execution and recovery package

**Why.** The current container reboots every 30–65 min (`docs/chemistry_progress.md`). Level 2 TD jobs need about 134 min from launch to their next durable checkpoint, so they cannot complete here. No paid compute has been provisioned; this package is what a stable machine or scheduler needs.

## Manifest

`records/portable_chemistry/manifest.json` (generated by `python3 phase1/portable_package.py`; regenerate after any new checkpoint). Per incomplete job:

- the exact command (`phase1/jobs.py` → `run_phase1.py`);
- dependencies;
- threads, declared peak memory and scratch;
- input geometries and initial guesses with sha256;
- every resume file with sha256: `td_ckpt/*/latest.npz`, `.prev`, `fingerprint.json`, `scf_*.chk`, `opt_*`;
- code sha256 for `phase1/*.py`;
- `requirements.txt` (pinned: numpy 2.5.3, scipy 1.18.1, pyscf 2.14.0, …) and the Python version (3.13).

Recommended machine: ≥ 16 GB RAM per two Level 2 jobs, ≥ 4 cores, ≥ 30 GB free disk, and **no preemption shorter than about 3 h** (or a scheduler with requeue, since jobs resume from checkpoints).

## Procedure

1. **Copy the repository** at the recorded commit, including `phase1/results/level2/`, `phase1/results/legacy_2026-10-09/level2_cam/` and `phase1/results/v2/<job>/` (excluding `scratch/`).
2. **Verify every sha256** in the manifest (inputs, resume files, code). A mismatch means a different starting point: do not resume; start that job fresh in a new directory.
3. **Install dependencies:** `pip install -r requirements.txt`.
4. **Run:** `cd phase1 && python3 jobs.py run --max-jobs N`. It admits through the shared budget (set `--max-jobs` to memory / 7 GB).
   - On a scheduler, wrap the same command. A requeued job resumes from `td_ckpt` (fingerprint- and orbital-validated) and from the converged geometry sidecar.
5. **Restart after interruption:** re-run step 4.
   - Stale "running" records are detected by boot ID / start time / command identity and relaunched.
   - Never delete `td_ckpt/`. `scratch/` is safe to delete.
6. **Validate outputs:**
   - `python3 jobs.py status` (completion markers with artifact sha256);
   - `phase1/compare_states.py` for state-character comparisons (TDA vs full TD, functionals, carboxylate);
   - root-coverage sensitivity is recorded in each `summary.json`.

## Not to change on the stable machine

Root counts, TD vs TDA, residual tolerances, basis, functional, solvent and chunk size, unless a separate, recorded sensitivity study is intended.
