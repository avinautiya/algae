# Milestone-1 completion report — safeguards, 2-D heat–moving-ice coupling, static debris shielding

**Safeguards.** No explicit list accompanied the request, so the following concrete weaknesses of milestone 0 were fixed and tested: (1) data loaders now verify the pinned size/MD5 before ingesting and refuse a corrupted archive; (2) `run` exits with a clean message (code 2) instead of a traceback; (3) synthetic/component runs refuse closures claiming `measured` provenance; (4) closure parameters enter the restart fingerprint; (5) the toe stock no longer silently clips a small negative stock — the roundoff correction is recorded and included in the budget; (6) exchange-record CSVs are validated on parse (mass, water-energy residual, latent/heat, time contiguity); (7) the stale second-order-flux comment in `stefan1DFoam.C` now matches its default (`fluxMode discrete`). 51 tests pass (`python -m ice_cliff_survival verify`; the CFD smoke test runs when the app is built).
**Implemented.** `cfd/stefan2DFoam` (2-D heat + moving ice, ALE), static debris shielding (per-row conductance, mapped from a wedge by `geometry.shield_conductance`), a conservative remap tool, `heat-ice-2d` CLI (component runs only).
**Verified (details in `cfd/VERIFICATION.md`).** 1-D limit vs the exact Neumann solution with density jump (first order in the mesh, dt-insensitive, rows identical); discrete energy ledger ≤ 2.4e-13; physical sensible+latent residual first order in dt (4.2e-4 at 2.5 s), reported separately; geometric conservation ≤ 1e-13; independent 2-D space and time series (spatial first order, temporal error below spatial); conservative remap to 2e-16; shielded cases vs the quasi-steady analytic solution (≤ 1.3e-3, scales with Ste) and bare/adiabatic limits. A real defect (meltwater enthalpy at the shield face temperature) was found by the ledger and fixed.
**Profile.** 6.4–8.3 µs per cell-step, 74 MB, ≤ 7 MB disk per case. The earlier campaign estimate (~9 CPU-h) is retained only conditionally: flow solves, not the heat–interface part, dominate, and the flow hand-over is unimplemented and unmeasured (`DECISIVE_COMPARISON.md`).
**Assumed / limited.** Uniform liquid inflow for ρ_i ≠ ρ_w (identity-by-construction mass check), no flow/free surface/grains, debris without heat capacity, k_deb assumed, temperate ice.
**Unfinished by design.** Mobile-grain transport coupling (explicit `UnsupportedRun`), dynamic shield feedback, in-run remeshing, solver checkpointing.
