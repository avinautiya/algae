Metadata for Lake Kennicott bathymetry at Kennicott Glacier, AlaskaData for Petersen, E., R. Hock, M. Loso, W. Guo, C. Markovsky, R. Yang, H. Han, D. Shangguan, and S. Kang, “Multi-year glaciological and meteorological observations on debris-covered Kennicott Glacier, Alaska, 2008-2023,” Geoscience Data Journal, Submitted January 2025.Data collected by the National Park Service (NPS)/Loso‘Bathymetry’ folder contains two subfolders: ‘East Lake bathymetry’ and ‘Southwest Lake bathymetry’. Each contains a single raster file in geotiff format packaged with deflate compression. Values in each raster reflect measurements collected 21-23 August 2018 as described in the text. Pixel values are bed elevations in meters height above ellipsoid, and these values can be translated into water depths by subtraction from the measured lake surface height at the time of acquisition: 428.96 m for the east lake and 428.68 m for southwest lake. Each subfolder also contains a single csv file with coordinates (lat long) and depths (measured distance from bed to water surface in meters) of raw measurements. Spatial reference for both rasters is WGS 1984 and elevations are presented as WGS 1984 ellipsoid heights with units meters. Interpolated bed elevations are rendered with 2-meter pixels.
