# Freeze of the capture-theory test (written and committed before any test case is run)

* Development configurations: D01-D16 (`design.DEV`), network r17 for thermal / dissipation-only / fixed-geometry treatments, completed 48/48 before this freeze (results in `eval_dev.json`).
* Theory under test: the reduced translation-invariant model RTM (`rtm.py`, tabulated once from the production kernels at the initial geometry; 17 stations for comparison with network r17, 33 stations for comparison with the resolved reference) and the quasi-steady-lake capture quantities (kappa, capture threshold gap, sigma). Code state: commit of this file. Nothing in RTM or the test design may change after this commit.
* Test configurations: T01-T16 (`design.TEST`), 16 configurations; predictions for all of them are in `TEST_PREDICTIONS.json/.md` (generated by `freeze_predictions.py` from `pred_test/*.json`), file hash recorded in `TEST_PREDICTIONS.sha256`. The configurations were chosen from RTM scans (no test simulation had been run) to lie on both sides of: (i) the quasi-steady capture threshold gap (T01/T02, T04/T05), (ii) the horizon-limited gap-drift sign change predicted by RTM (T02/T03, T05/T06), (iii) the 12 h switching boundary (T07-T10), plus pulsed forcing, symmetric pairs, reversed geometry and a cold case.
* Runs: network r17 for T01-T16 with three treatments (thermal, dissipation-only T2 surrogate, fixed geometry); network r33 (thermal) and the independent 1-D resolved reference (200 and 400 cells, thermal and fixed geometry) for the six informative cases T01, T02, T04, T05, T07, T13. Runtime estimate before launch: network r17 about 10-30 s per run (48 runs, two workers: 15 min), r33 about 60-150 s (6 runs), reference 200 cells about 80 s and 400 cells about 300 s (24 runs, two workers: about 35 min). No resolution was reduced; the 200/400-cell pair is the convergence evidence for the reference (order assumed about 0.9 from the frozen-set measurements, flagged).
* Acceptance rules: (a) switching occurrence agrees; a case is a *near tie* when either t_dom2 exceeds 0.85 of the horizon (43 200 s) or |phi2_end - 0.5| < 0.03 (not scored); (b) switching time within 10 % where both switch and not near-tie; (c) gap-drift sign (gap = sill-2 minus sill-1 elevation; drift = change over the second half of the run) agrees when both |drift| exceed 2 mm, otherwise flat/near-tie; (d) delivered share phi2 within 0.03; (e) inlet-sill lowering of each route within 15 % (minimum 1 mm). Cases where neither route delivers water are reported as non-draining and never counted as correct routing predictions.
* Comparators: fixed geometry (no incision), dissipation-only incision (SaDS-type surrogate inside our hydraulics, not SaDS), the existing thermal network (r17/r33) and the resolved reference. RTM is **not** an independent physics model: agreement with network r17 tests the approximations (translation invariance, tabulated rates, one lake ODE), agreement with the reference tests physics and numerics at shared closures.
* If a defect is found the test version stays as published and a new independent assessment is required.
