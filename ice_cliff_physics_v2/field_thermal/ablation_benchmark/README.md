# Conditional ablation transfer benchmark

Four explicitly author-linked stake/profile origins, all twelve directed origin-to-target edges, four families (distributed diffusion, quasi-steady, one-node diffusion, source-origin constant daily mass loss). No published conductivity is used. Each thermal family calibrates its own scalar conductivity on the SAME source mass total only. Each column's diffusivity is fit on its first14days of measured temperatures using the frozen61point log grid,1e-8–1e-5m²/s. Targets' subsequent ablation masses do not enter fitting.

All combinations of profile/stake thickness, earlier/current leading2020 installation geometry, and start/end ADT date shifts−12/0/+12h are reported. Date-only records are mapped to00:00ADT=08:00UTC by declared convention; timestamps in code are explicitly UTC independent of machine locale.2023 missing leading forcing is NOT measured: the secondary full-period estimate repeats the first complete observed24h positive-flux pattern by time-of-day. Zero/maximum-first14day daily-rate leading-loss choices give conditional conductivity scenarios, not rigorous partial-day bounds or statistical intervals. Covered-period prediction exceeding full seasonal measured mass is a one-sided contradiction only under the stated nonnegative-ablation assumptions; passing does not establish covered-period accuracy.

2020 raw measured temperatures cover the mass period. Exact installation transition is unverified. Early source geometry is tested at0.5/18cm and5/15cm; both switch to confirmed5/15cm geometry at the first processed timestamp. Each domain is initialized from its actual first real probe vector and assumed basal0; resetting there is an explicit installation/initial-state sensitivity, NOT a verified continuous material history.

The thermal model is homogeneous conductive debris from measured shallow probe to an assumed temperate ice boundary. It omits top debris above that probe, phase enthalpy, nonconductive transport, and changing depth. It does not validate stream/cliff physics, local water contact, regional Himalayan melt, or future weather forecasting. Signed negative basal gradients are retained separately; positive-gradient loss is a labelled melt-only approximation.

Run `PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 python3 run.py`. The64/128mode check and signed moment audit are included; these numerical checks do not validate omitted physical processes. No result is selected by its success.
