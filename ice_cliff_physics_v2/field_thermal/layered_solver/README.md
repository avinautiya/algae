# Fixed-midpoint two-layer diffusion diagnostic

This is a conventional conservative finite-volume discretization of Cvol T_t=(k T_z)_z, with common constant Cvol, alpha_top=k_top/Cvol and alpha_bottom=k_bottom/Cvol. Layer boundary is fixed at the domain midpoint; cell count must be even. No interface position is fitted. Endpoint temperatures are prescribed measured series; initial temperature interpolates all first-row probes once. No later interior assimilation, missing support or gap filling is allowed. Negative temperatures are permitted; no phase change is represented.

Cell-centred interface conductances use harmonic means. Boundary half-cell conductance uses2alpha. The resulting symmetric negative-definite tridiagonal generator is independently diagonalized. For each piecewise-linear boundary interval, subtract the instantaneous steady series-resistance profile; residual eigenmodes advance by the exact exponential/phi recurrence. Thus time integration is exact for the discretized operator and declared linear boundary forcing. Uniform series use scipy.signal.lfilter; irregular supported series use direct recurrence. Spatial error remains. Predictions interpolate in thermal-resistance coordinate so an observation exactly at the conductivity interface respects the gradient jump.

API: PreparedLayered(times_s,top,bottom,depths,initial_depths,initial_temperatures,cells=40,max_gap_s=300).predict(alpha_top,alpha_bottom). Output shape(time,target). history(...) returns cell centres. operator(...) exposes generator diagonals and face diffusivities for independent ledger checks. Units: metres,seconds,Celsius,m2/s. Only diffusivities are inferred by an external frozen training protocol; absolute conductivity/heat flux cannot be inferred from temperature alone.

Four tests pass: homogeneous sine solution second-order convergence20/40/80cells; exact steady two-layer series resistance; finite-volume summed tendency equals signed endpoint flux and positive initial/boundary data preserve positivity; unsupported gaps refused. A test caught and corrected ordinary interpolation across the conductivity jump before release. These tests establish implementation checks, not field improvement. N40/80 field prediction convergence must be audited independently, particularly when optimizing high diffusivity contrast. Runtime/memory scale with number of timestamps and cells; the backend stores cell histories and has no production parallel scheduler. This is classical diffusion, not claimed as novel mathematics.
